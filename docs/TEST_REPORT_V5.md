## 🐛 已知问题

### 已修复问题

1. ✅ **showToast 未定义错误**
   - 位置：js/qimen.js
   - 原因：缺少 import 语句
   - 修复：添加 `import { showToast } from './utils.js'`

2. ✅ **CSS 版本号不一致**
   - 位置：index.html
   - 原因：CSS 文件版本号是旧的
   - 修复：更新为 `v=20260624-2`

3. ✅ **按钮样式不统一**
   - 位置：css/components.css
   - 原因：导出按钮样式与其他按钮不一致
   - 修复：统一按钮样式

4. ✅ **导航栏展开后文字不显示**
   - 位置：css/base.css
   - 原因：缺少 transition 属性
   - 修复：添加 CSS transition

### 已知限制

1. **PDF 导出依赖 CDN**
   - 需要联网加载 jsPDF 和 html2canvas
   - 首次加载可能需要 2-3 秒

2. **分享链接长度限制**
   - Base64 编码的 URL 较长
   - 复杂数据可能超过某些平台的 URL 长度限制

3. **指南针 API 需要 HTTPS**
   - DeviceOrientationEvent 需要安全上下文
   - 本地开发可能无法使用
