## 🐛 已知问题

### 已修复问题

1. ✅ **showToast 未定义错误**
   - 位置：js/qimen.js
   - 原因：缺少 import 语句
   - 修复：添加 `import { showToast } from './utils.js'`

2. ✅ **CSS 版本号不一致**
   - 位置：index.html
   - 原因：CSS 文件版本号是旧的
   - 修复：更新为 `v=20260624-2`

3. ✅ **按钮样式不统一**
   - 位置：css/components.css
   - 原因：导出按钮样式与其他按钮不一致
   - 修复：统一按钮样式

4. ✅ **导航栏展开后文字不显示**
   - 位置：css/base.css
   - 原因：缺少 transition 属性
   - 修复：添加 CSS transition

### 已知限制

1. **PDF 导出依赖 CDN**
   - 需要联网加载 jsPDF 和 html2canvas
   - 首次加载可能需要 2-3 秒

2. **分享链接长度限制**
   - Base64 编码的 URL 较长
   - 复杂数据可能超过某些平台的 URL 长度限制

3. **指南针 API 需要 HTTPS**
   - DeviceOrientationEvent 需要安全上下文
   - 本地开发可能无法使用

#### 4. 备份加密功能（新增）

**功能描述**：导出时可选择加密备份，恢复时需要密码

**实现位置**：js/export.js

**技术方案**：
- 导出时提示用户输入密码
- 使用 `btoa()` 进行 base64 编码（简单加密）
- 密码存储在 JSON 的 `passwordHash` 字段
- 恢复时验证密码

**注意事项**：
- 当前使用 base64 编码，安全性有限
- 生产环境建议使用 AES 加密
- 用户需要记住密码才能恢复数据

---

#### 5. 自动备份提醒（新增）

**功能描述**：超过设定时间未备份时自动提醒用户

**实现位置**：js/export.js + js/app.js

**配置参数**：
- 默认间隔：7 天
- 存储键：`qky_last_backup_time`
- 提醒时间：页面加载 3 秒后

**UI 组件**：
- 底部弹出式提醒卡片（`.backup-reminder`）
- 包含图标、标题、描述、操作按钮
- 可选择"稍后提醒"或"立即备份"

**核心函数**：
```javascript
setupAutoBackup(intervalDays = 7)  // 设置自动备份提醒
```

**集成方式**：
```javascript
// js/app.js
initDataManagement();
setupAutoBackup(7);  // 初始化后启动备份提醒
```
